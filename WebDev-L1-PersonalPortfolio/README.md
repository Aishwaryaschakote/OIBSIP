# Personal Portfolio

This project is a responsive personal portfolio website developed as part of the **Web Development & Designing Internship** at **Oasis Infobyte**.

The portfolio showcases my background, technical skills, projects, and contact information in a clean and responsive design.

## Features

- Responsive hero section with name and role
- About Me section
- Technical Skills section
- Projects section
- Contact section
- Navigation between sections
- Smooth scrolling
- Responsive design for desktop, tablet, and mobile devices
- Consistent colour scheme and typography

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Portfolio Sections

### Home
Introduction with my name, role, and a short overview.

### About Me
Information about my educational background, interests, and career goals.

### Skills
A collection of my technical skills and technologies.

### Projects
Showcase of selected academic, internship, and personal projects.

### Contact
Contact information and links to my professional profiles.
