# Temperature Converter

This project is an interactive temperature converter developed as part of the **Web Development & Designing Internship** at **Oasis Infobyte**.

The website allows users to convert temperature values between **Celsius, Fahrenheit, and Kelvin** with input validation and a simple, responsive interface.

## Features

- Temperature input field
- Celsius, Fahrenheit, and Kelvin unit selection
- Converts temperature into all three units
- Convert button for performing calculations
- Displays converted values with clear unit labels
- Validates numeric input
- Handles absolute zero violations
- User-friendly error messages
- Clean and responsive design
- Works on desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Conversion Units

The converter supports:

- **Celsius (°C)**
- **Fahrenheit (°F)**
- **Kelvin (K)**

The conversion is performed using JavaScript based on the selected input unit.
